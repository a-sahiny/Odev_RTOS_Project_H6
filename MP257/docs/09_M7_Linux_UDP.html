Kopyalama ve M33’ü başlatma

Ne oluyor? Yeni M33 programı ve telem_udp karta kopyalanır, M33 yeniden başlatılır.
PC’de (PowerShell)
# M33 programını kopyalar
scp C:\zephyrproject\mp257_m33_derleme\zephyr\zephyr.elf root@192.168.7.1:/lib/firmware/mp257_m33.elf
# telem_udp’yi kopyalar
scp C:\Users\Asus\AppData\Local\Temp\telem_udp root@192.168.7.1:/root/telem_udp
# çalıştırma izni verir
ssh root@192.168.7.1 "chmod +x /root/telem_udp"
Kartta (ssh içinde)
# M33’ün klasörüne girer
cd /sys/devices/platform/ahb@1/0.m33/remoteproc/remoteproc*
# adı gösterir; m33 olmalı
cat name
# durdurur
echo stop > state
# başlatır
echo start > state

Beklenen sonuç: /dev/rpmsg0 oluşur.

Olmazsa: name satırı m33 değilse dur.
