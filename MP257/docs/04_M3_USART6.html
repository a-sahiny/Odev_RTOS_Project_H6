M2’nin son testi

Durdur ve yeniden başlat

Amaç: M33’ün istenince durduğunu, aynı programla yeniden başladığını ve LED’i gerçekten bizim programın yaktığını görmek.
1

Durdurma

Ne oluyor? Linux’a "M33’ü durdur" denir. Linux çalışmaya devam eder. Bu komutları o gün remoteproc0 adıyla yazmıştık; nedenini 04 numaralı bölümde okuyacağın için burada doğru hâlleri var.
PC’de (PowerShell)
# M33’ün sabit klasörüne gir (cd) ve durdur; &&: önceki başarılıysa devam et
ssh root@192.168.7.1 "cd /sys/devices/platform/ahb@1/0.m33/remoteproc/remoteproc* && echo stop > state"
# durumu ve çekirdeğin son 5 kaydını göster (tail -n 5: son 5 satır)
ssh root@192.168.7.1 "cd /sys/devices/platform/ahb@1/0.m33/remoteproc/remoteproc* && cat state; dmesg | tail -n 5"

Beklenen sonuç: offline, stopped remote processor m33, LD9 yanıp sönmeyi bırakır. GEÇTİ Kartta böyle oldu.

Olmazsa: durum offline değilse devam edilmez.

remote FW shutdown without ack uyarısı beklenen bir satır: programımız Linux’un kapanma mesajına cevap vermiyor, Linux 500 ms bekleyip yine de durduruyor.

UART’ı neden USB’ye bağlamadık?

F746’yı USB ile takarsak veriyi M33 değil Linux alır. Amaç baytları Zephyr’in alması. Bu yüzden iki kart arasında tel var; USB yalnız PC’ye giden yollarda.

app_isr.c: USART6 kesmesi

MP257/zephyr/src/app_isr.c
1/* USART6 kesmesi: baytları taşır, tur bitince main thread'ini uyandırır. */2#include "app.h"3#include <zephyr/drivers/uart.h>4 5/* Gelen baytları diziye alır, giden baytları hatta verir. */6void uart_isr(const struct device *dev, void *user_data)7{8    (void)user_data;9 10    uart_irq_update(dev);                            // diğer uart_irq çağrılarından önce şart11 12    if (uart_err_check(dev) > 0)13    {14        ++rx_errors;                                 // taşma, çerçeve ya da gürültü hatası15    }16 17    if (uart_irq_rx_ready(dev) > 0)18    {19        uint8_t byte;20 21        while (uart_fifo_read(dev, &byte, 1) == 1)22        {23            if (rx_count == LOOP_SIZE)24            {25                ++rx_errors;                         // dizi dolu: fazla bayt atılır26                continue;27            }28 29            rx_data[rx_count] = byte;30            ++rx_count;31 32            if (rx_count == LOOP_SIZE)33            {34                k_sem_give(&rx_done);35            }36        }37    }38 39    if (uart_irq_tx_ready(dev) > 0)40    {41        if (tx_count < LOOP_SIZE)42        {43            tx_count += uart_fifo_fill(dev, &tx_data[tx_count], LOOP_SIZE - tx_count);44        }45        else46        {47            uart_irq_tx_disable(dev);                // kapatılmazsa kesme durmadan gelir48        }49    }50}
SatırNe yapar

uart_err_checkDonanım hatası varsa sayılır, sessizce geçilmez
uart_fifo_read döngüsüGelen baytları alır; dizi doluysa fazlası hata sayılır, bellek taşmaz
k_sem_give1000. baytta thread’i uyandırır
uart_fifo_fillSıradaki baytları donanıma verir
uart_irq_tx_disableGönderecek kalmayınca kapatılır; kapatılmazsa kesme durmadan gelir

main.c: bir tur (run_round)

MP257/zephyr/src/main.c
24/* 1000 bayt yollar, geri geleni karşılaştırır; aynıysa 1, değilse 0 döner. */25static int run_round(void)26{27    // Kesme açılmadan sıfırlanır; yoksa ilk baytlar eski sayaçla işlenir28    tx_count = 0;29    rx_count = 0;30    memset(rx_data, 0, sizeof(rx_data));31    k_sem_reset(&rx_done);32 33    uart_irq_tx_enable(uart);34 35    // 1000 bayt 460800'de 21,7 ms sürer; 100 ms üst sınır36    if (k_sem_take(&rx_done, K_MSEC(100)) != 0)37    {38        return 0;39    }40 41    return rx_errors == 0 && memcmp(tx_data, rx_data, LOOP_SIZE) == 0;42}

Sayaçlar gönderme kesmesi açılmadan sıfırlanır. k_sem_take bekleme döngüsü değildir: thread uyur, 1000. baytta uyanır; 100 ms yalnız üst sınırdır. Sonra hata sayısı ve içerik karşılaştırılır.
