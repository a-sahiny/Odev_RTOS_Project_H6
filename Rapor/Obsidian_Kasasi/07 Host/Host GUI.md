# Host GUI

tkinter arayüz: Kontrol, Uçuş (IMU), MP257 (UDP), Telemetri, Kaynaklar, Sayaçlar, Testler, Günlük.

Port listesinin varsayılanı **Otomatik (Linux, yoksa F746)**: telem_udp'yi başlatır, seri port gerekmez. Uçuş ve MP257 sekmeleri aynı kaynağı ve aynı gecikme tablosunu gösterir; STOP, test ya da bağlantı kesme Uçuş'u durdurmaz.
